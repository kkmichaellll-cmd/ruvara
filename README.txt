RUVARA NAILS

Open index.html in Chrome, Edge, Firefox, or Safari. Upload the folder contents to the root of a static host to publish it. No build step is required.

The site uses Ruvara’s original copy, gallery photographs, prices, appointment information, testimonials, and FAQ. The hero contains a new editorial portrait. Bodoni Moda and DM Sans are provided under the enclosed licenses.

Photo and font assets load from their public hosts. To save those assets locally as well, run node download-assets.mjs once with Node.js 20 or newer. The site works online immediately.

Appointment buttons open the studio’s original WhatsApp link. The enquiry form opens WhatsApp with a prepared message that the visitor can review and send.
